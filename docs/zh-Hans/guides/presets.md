# 预设预览

在下方切换完整预设。使用工具栏中的“自定义”查看继承的尺寸、覆盖单项设置并复制生成的代码。切换预设时，显式组件覆盖项仍会生效；使用“重置”比较未修改的预设。

编辑器、工作区设置和导出任务场景组合展示了字段、选择控件、操作和进度指示器。打开对话框和底部/侧边面板，也可比较它们的间距。各组件示例位于这些场景之后。
